# HexedNET

HexedNET started as a fork of [WSUTComp](https://github.com/zenakuten/WSUTComp) to extracts the lag compensation from the rest of features inside UTComp.
Now it became its own implementation of lag compensation, with most of the code base entirely rewritten, although the underlying compensation techniques are the same.
Releases are bundled together with HexedUT (see [HexedUT2k4](https://github.com/hexengraf/HexedUT2k4)), with detailed configuration instructions [here](https://github.com/hexengraf/HexedUT2k4/blob/master/CONFIGURATION.md).
